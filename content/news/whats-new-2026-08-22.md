# Agenthood v3.38.0: Steward Load Routing and CI Fix

**Date:** August 22, 2026  
**Author:** Agenthood Team

We've shipped v3.38.0 with a reframed steward load routing model, a new mediator component, and a fix for CI checkout.

## v3.38.0

### Steward Load Routing and Mediator

- **Steward load routing:** Reframed how steward load is routed to improve clarity and flexibility. This change closes issue #474.
- **The mediator:** Added a new mediator component to support the reframed routing model.

### CI Checkout Fix

- **Githubfx gitlink:** Removed a stray Githubfx gitlink that was breaking CI checkout. This resolves issue #483.
