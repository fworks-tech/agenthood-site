# v3.75.0: Protocol-Aware OpenCode Zen With Jev System One

**Date:** October 9, 2026
**Author:** Agenthood Team

We've shipped Agenthood v3.75.0, a focused release for the Llm module. The OpenCode Zen provider is now protocol-aware, and it gains support for a new model, Jev System One.

## v3.75.0 — 2026-10-08

### OpenCode Zen provider improvements

- **Protocol-aware behavior:** The OpenCode Zen provider now adapts its request and response handling based on the protocol in use. This makes the provider more resilient to protocol differences and improves compatibility across environments.
- **Jev System One support:** The provider now works with Jev System One, expanding the range of models you can run through OpenCode Zen. No additional configuration is required beyond selecting the model as you normally would.

Pull request [#1012](https://github.com/fworks-tech/agenthood/compare/v3.74.0...v3.75.0) includes the underlying changes, and the work also references issue #589 for tracking.
