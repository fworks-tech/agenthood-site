# Agenthood v3.71.1: Opencode plugin specifier fix

**Date:** September 30, 2026  
**Author:** Agenthood Team

## v3.71.1

### Opencode plugin specifier handling

- **Component:** Opencode
- **Fix:** Bare plugin specifiers are now supported without terminating the host process. Previously, passing a plugin specifier without a scope or prefix could cause the host to exit unexpectedly. This release resolves that behavior and allows bare specifiers to be used normally.
- **Reference:** This addresses issue #990 and is included in pull request #991.
