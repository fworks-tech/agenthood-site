# Agenthood Release Digest: v3.67.0 and v3.66.0

**Date:** September 21, 2026  
**Author:** Agenthood Team

## v3.67.0 — Provider health, timeouts, memory TTL, and tool safety

Today's release tightens runtime behavior around provider health, request timeouts, short-term memory, and skill tool permissions.

### Health probes with real requests
- **Health:** provider health checks now send a real request instead of a synthetic ping, so status reflects actual end-to-end availability.

### Configurable per-request timeout
- **LLM:** provider calls accept a per-request timeout, giving finer control over slow or unresponsive providers.

### Short-term memory TTL and pruning
- **Memory:** short-term memory entries support a TTL option, and residual signals are pruned when a record is written.

### Enforced allowed-tools from SKILL.md
- **Safety:** the allowed-tools list in SKILL.md frontmatter is now enforced, preventing skills from invoking tools outside their declared set.

## v3.66.0 — CLI, init, and skill workflow improvements

Yesterday's release focuses on the command-line experience, project initialization, and skill management.

### CLI and logging
- **CLI:** new `--json` flag enables pino structured logging for machine-readable output.
- **CLI:** shared error formatter standardizes error messages and exit codes across commands.

### Project initialization
- **Init:** `--ci` flag supports non-interactive setup with `--runtime` and `--members`.
- **Init:** `--target` flag allows cross-client compatibility.
- **Init:** new projects get `.agents/skills/` as the primary cross-client location.
- **Init:** prompts before overwriting an existing setup.

### Skill and member management
- **Create:** scaffolds new skills from a template.
- **Diff:** shows drift between installed members and the lockfile.
- **Eject:** sweeps lockfiles alongside artifacts.
- **List:** shows token counts and context budget.
- **Remove:** clean uninstall with lock pruning.
- **Skills:** discovers skills in a bare `skills/` directory.

### Sandbox and runtime
- **Run:** `--sandbox` flag enables a strict local profile.
- **Sandbox:** detects Docker container isolation.

### Upgrade
- **Upgrade:** self-upgrade command with config backup.

### Bug fixes
- **CI:** reviewer empty-tree range fixed.
- **Docs:** corrected non-existent member references and tool vocabulary.
