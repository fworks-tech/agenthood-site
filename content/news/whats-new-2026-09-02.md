# Agenthood v3.39.2: Provider Failover Hardening

**Date:** September 2, 2026
**Author:** Agenthood Team

## v3.39.2

We've shipped v3.39.2, a patch release focused on the LLM layer. This release hardens provider failover behavior to make routing more predictable and resilient.

### Provider failover improvements

- **LLM:** hardened provider failover priority, per-entry keys, and cheap retry logic. The fix ensures that failover respects the configured priority order more strictly, that per-entry keys are handled correctly when providers are swapped, and that retries are attempted without unnecessary overhead.

This release is available now. No breaking changes are included.
