# Agenthood Release Digest: September 13, 2026

**Date:** September 13, 2026
**Author:** Agenthood Team

We've shipped two patch releases on September 12, 2026, addressing issues in the verify command and the build scripts.

## v3.63.3

### verify

- **Placeholder scan:** narrowed to the marker form and now skips code spans, preventing false positives in placeholder detection. This resolves issues #816 and #753.

## v3.63.2

### scripts

- **Marked options:** removed deprecated options that were dropped in marked v15 and v18, restoring compatibility with current marked versions.
