# Agenthood v3.74.0 Adds OpenCode Client Session Backend

**Date:** October 8, 2026  
**Author:** Agenthood Team

## v3.74.0

### Llm

- **OpenCode client session backend:** `agenthood run` now supports an OpenCode client session backend, giving teams another session persistence option when running agents. If your workflows already use OpenCode, you can keep agent activity in the same session infrastructure.
