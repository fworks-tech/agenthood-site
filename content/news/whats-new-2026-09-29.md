# Agenthood v3.71.0: Goal command, concurrency arbitration, and trajectory persistence

**Date:** September 29, 2026  
**Author:** Agenthood Team

We've shipped v3.71.0 with three focused improvements to goal handling, runtime scheduling, and trace persistence.

## v3.71.0

### Goal command backed by GoalChain

- **Goals:** a new `goal` command is now available, backed by the GoalChain system. This gives agents a structured way to define and execute multi-step objectives rather than relying on ad-hoc instructions. The command integrates with GoalChain to provide a consistent execution path for goal-driven tasks.

### Runtime arbitration through ConcurrencyQueue

- **Runtime:** member runs are now arbitrated through a ConcurrencyQueue, keyed by origin. This allows the runtime to manage concurrency per origin, reducing interference between runs from different sources and providing more predictable scheduling under load.

### One-step trajectory persistence

- **Trace:** the trace system now persists a one-step trajectory on both run success and failure. This gives you a consistent record of the immediate action taken, which is useful for debugging and auditing agent behavior regardless of outcome.
