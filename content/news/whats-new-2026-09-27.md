# Agenthood Release Digest: v3.68.1–v3.68.3

**Date:** September 27, 2026  
**Author:** Agenthood Team

Here's what's new in the latest Agenthood patch releases. We've focused on cleaning up Herald's release-note generation, tightening Dependabot grouping, and updating our test tooling.

## v3.68.3 — September 27, 2026

### Dependabot grouping no longer swallows 0.x majors
- **Dependabot:** the minor-patch group now stops absorbing 0.x major updates, and the four safe dependency bumps have landed.

### Herald changelog deduplicates trailing references
- **Herald:** the changelog now dedupes the trailing reference pile, matching the release-notes behavior.

### Herald release notes stop leaking issue references
- **Herald:** release notes no longer leak issue refs, and the changelog no longer claims false closures.

### Herald linkify artifacts no longer corrupt release notes
- **Herald:** linkify artifacts are prevented from corrupting release notes.

## v3.68.2 — September 26, 2026

### Vitest timeout raised to fix flaky tests at the root
- **Test:** we've raised the Vitest timeout to address the underlying cause of flaky tests rather than patching individual cases.

### @types/vscode held at the engines.vscode floor
- **VS Code extension:** @types/vscode is now pinned to the minimum version required by engines.vscode, keeping type definitions aligned with the supported API surface.

## v3.68.1 — September 26, 2026

### Vitest 5 with coverage provider and hoisted mocks
- **Dev dependencies:** we've bumped Vitest to 5, updated the coverage provider, and hoisted nested mocks.
