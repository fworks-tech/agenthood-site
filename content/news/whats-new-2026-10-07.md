**Date:** October 7, 2026  
**Author:** Agenthood Team

We've shipped two releases since the last digest. The headline is v3.73.0, which brings the VS Code extension to a stable 1.0.0 milestone. We also released v3.72.1, a patch with an empty changelog.

## v3.73.0 — VS Code extension hits 1.0.0

### Extension publish-ready
- **Component:** VS Code extension
- **Description:** Bumped to v1.0.0 in preparation for Marketplace publish.

This marks the extension's first stable version, clearing the way for a public listing on the Marketplace. The version bump is the only change in this release.

## v3.72.1 — Patch release

No changelog entries were included with this patch release, so no user-facing changes are recorded. It ships as an incremental maintenance update between v3.72.0 and v3.73.0.
