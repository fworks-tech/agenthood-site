# News Article Contribution Guide

How to write, register, and publish news articles for the Agenthood site.

## Article Format

Articles live in `content/news/` as markdown files with YAML front matter:

```markdown
---
title: "Your Article Title"
date: 2026-09-08
author: Agenthood Team
summary: "A one-sentence summary used for the news listing and RSS feed."
---

# Your Article Title

**Date:** September 8, 2026
**Author:** Agenthood Team

Article body in markdown. Sections separated by `---` horizontal rules.
```

### Front Matter Contract

| Field     | Required | Format        | Notes                                      |
|-----------|----------|---------------|--------------------------------------------|
| `title`   | Yes      | String        | Must match the first `# ` heading exactly  |
| `date`    | Yes      | `YYYY-MM-DD`  | Publication date                           |
| `author`  | Yes      | String        | Display name (usually "Agenthood Team")    |
| `summary` | Yes      | String        | One sentence, used for listings and RSS    |

### Section Structure

Long-form articles (like the AI trends series) should:

1. Use `##` headings for major sections
2. Separate sections with `---` horizontal rules
3. Include press references between sections as markdown links:

```markdown
---

**Press:** [Article Title](https://example.com/source) · Supporting statistic ([Source](https://example.com/stats))
```

## Manifest Registration

Articles are registered in `content/news/manifest.json`, generated by `scripts/build-news-manifest.mjs`. The manifest is rebuilt automatically:

- **Local dev:** `npm run sync-news` (runs in lenient mode — invalid articles warn but don't block)
- **Production build:** `npm run build` (strict mode — invalid articles fail the build)

Run `npm run sync-news` after adding or editing an article to regenerate the manifest.

### Manifest Entry Shape

```json
{
  "slug": ["your-article-slug"],
  "path": "news/your-article-file.md",
  "title": "Your Article Title",
  "date": "2026-09-08",
  "author": "Agenthood Team",
  "summary": "A one-sentence summary."
}
```

Slugs are derived from the filename (without `.md`). Multiple slugs can route to the same article.

## RSS Feed

The RSS feed at `/news/rss.xml` is generated from the manifest at build time. No separate RSS update is needed — once an article is in the manifest, it appears in the feed automatically.

## PR Checklist

Before submitting a news article PR:

- [ ] Front matter has all four required fields (`title`, `date`, `author`, `summary`)
- [ ] `title` matches the first `# ` heading exactly
- [ ] `date` is in `YYYY-MM-DD` format
- [ ] `npm run sync-news` runs without errors
- [ ] Article renders correctly in local dev (`npm run dev`, visit `/news`)
- [ ] Summary is one sentence, suitable for listing cards and RSS
